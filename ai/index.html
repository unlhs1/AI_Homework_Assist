预设

协议 / 端点

学段定性（分类 Agent，推荐轻量非推理模型）

专门给「题目是哪个学段」定性用，推荐百炼 qwen 轻量模型（秒级返回）。留空 = 用上方主配置；主配置是 DeepSeek 推理模型时定性会很慢。

🧠 思考强度（推理预算）

以模型 API 层参数控制推理深度（reasoning_effort：low/medium/high，百炼 qwen 还有 enable_thinking 可关思考），同时配 max_tokens 预算与提示词。off=快速行动（百炼模型可关闭思考）；low=轻度；high=深度（默认）；max=极致（充分推演+多方案）。任何档位代数计算仍走草稿纸，不脑内算。

📚 上下文长度（token 预算，默认 1M）

对话历史累积超出预算时自动裁剪**最旧的完整轮次**（保留 system + 最新轮），防止请求超长。默认 1M 基本永不触发，历史完整保留。
